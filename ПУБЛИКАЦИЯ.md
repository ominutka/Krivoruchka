# Публикация на itch.io

itch.io раздаёт только статичные файлы, а «Криворучка» без сервера не
работает. Поэтому публикация состоит из двух частей:

- **сервер** живёт на бесплатном хостинге и работает круглосуточно;
- **страница игры** лежит на itch.io и обращается к этому серверу.

Порядок такой: сначала поднять сервер, потом собрать страницу с его
адресом, потом выложить.

---

## Часть 1. Сервер на бесплатном хостинге

Ниже — Render, потому что он не требует карты. Railway, Fly или Glitch
настраиваются похоже.

### 1. Заведите репозиторий на GitHub

Нужен аккаунт на **github.com**. Создайте новый репозиторий, например
`krivoruchka`, и залейте туда содержимое этой папки.

Проще всего через сайт: **Add file → Upload files**, перетащить все
файлы и папки, нажать **Commit changes**. Папку `node_modules`, если
она появилась, загружать не нужно.

### 2. Создайте сервис на Render

1. Зайдите на **render.com**, зарегистрируйтесь через GitHub.
2. **New → Web Service**, выберите свой репозиторий.
3. Заполните поля:

   | Поле | Значение |
   |---|---|
   | Name | `krivoruchka` (станет частью адреса) |
   | Language / Environment | Node |
   | Build Command | оставить пустым |
   | Start Command | `node server.js` |
   | Instance Type | Free |

4. Нажмите **Create Web Service** и подождите пару минут.

Наверху появится адрес вида `https://krivoruchka.onrender.com` — это и
есть ваш сервер. Откройте его в браузере: должна открыться игра.

**Запомните этот адрес**, он понадобится на следующем шаге.

### Что нужно знать про бесплатный тариф

**Сервис засыпает** после 15 минут без посетителей. Первый заход после
паузы занимает до минуты — страница будет казаться зависшей. Решается
просто: откройте адрес сервера сами за минуту до начала, чтобы он
проснулся.

**Соединение может ненадолго рваться.** Игра держит постоянную связь с
каждым устройством, а бесплатный тариф даёт 0.1 процессорного ядра.
Браузер переподключается сам за секунду, игра это переживает: холст и
роли восстанавливаются, предупреждение показывается только если связи
нет дольше трёх секунд.

Если обрывы мешают играть — это первое, ради чего стоит перейти на
платный тариф (7 долларов в месяц): там нет ни засыпания, ни урезанного
процессора.

### Если Render не находит файлы

В логах строка вида `Could not read package.json`. Значит, при загрузке
на GitHub перетянулась сама папка, а не её содержимое, и файлы лежат
уровнем глубже.

Чинится без перезаливки: **Settings** → поле **Root Directory** → впишите
имя папки (например, `krivoruchka`) → **Save Changes**. Render пересоберёт
сервис сам.

### Build Command

Render не разрешает оставить это поле пустым, хотя собирать нечего.
Впишите `npm install` — команда отработает вхолостую за пару секунд.

## Часть 2. Сборка страницы

В папке проекта выполните команду, подставив свой адрес:

```
node build-itch.js https://krivoruchka.onrender.com
```

Появится файл **itch-krivoruchka.zip** — около 15 КБ. Внутри только
клиент: `index.html`, `roles.js` и `config.js` с вписанным адресом
сервера.

Адрес обязательно должен быть на `https`. itch.io отдаёт страницы по
защищённому протоколу, и обращения к обычному `http` браузер
заблокирует.

---

## Часть 3. Страница на itch.io

1. Зарегистрируйтесь на **itch.io**, затем **Upload new project**.
2. Заполните поля:

   | Поле | Значение |
   |---|---|
   | Title | Криворучка |
   | Kind of project | **HTML** |
   | Uploads | загрузите `itch-krivoruchka.zip` |
   | | отметьте галочку **This file will be played in the browser** |
   | Embed options | **Click to launch in fullscreen** или размер 1280 × 800 |
   | | включите **Mobile friendly** и **Fullscreen button** |
   | Pricing | `No payments` или `Donate` |
   | Visibility | сначала **Restricted**, потом **Public** |

3. Нажмите **Save**, затем **View page** — проверьте, что игра
   открывается и комната создаётся.

Пока стоит **Restricted**, страницу видите только вы и те, кому дадите
ссылку. Это удобно для проверки перед публикацией.

### Важная особенность

На itch страница открыта во фрейме, поэтому **ссылку с кодом комнаты
передать нельзя** — адрес в браузере не меняется. Игра это учитывает:
вместо ссылки она показывает код, а кнопка копирует именно код.

Друзьям нужно объяснить в описании: откройте страницу игры и введите
код, который назовёт первый игрок.

## Что написать на странице

**Короткое описание** (одна строка, видна в каталоге):

> Пати-игра, где карандаш один на всех, а кнопки разделены между вами.

**Полное описание.** Важно объяснить три вещи, иначе человек не поймёт,
что ему делать:

1. Нужны от 2 до 6 человек, каждый со своего устройства.
2. Один создаёт комнату и называет код, остальные его вводят.
3. На компьютере играют с клавиатуры — мышью две кнопки сразу не нажать.

Готовый текст можно взять из [ПРАВИЛА.md](ПРАВИЛА.md): разделы
«Главное правило», «Роли» и «Режимы» подходят почти без правок.

**Скриншоты.** Сделайте несколько кривых рисунков кнопкой «Сохранить» —
это лучшая реклама игры. Подпишите, что должно было получиться.

**Теги:** `multiplayer`, `party-game`, `drawing`, `local-multiplayer`,
`funny`, `co-op`.

## Обновление игры

Правки в `public/` — пересоберите и загрузите новый архив на itch:

```
node build-itch.js https://ваш-адрес
```

Правки в `server.js` — залейте изменения на GitHub, Render подхватит их
и перезапустится сам.

Учтите: перезапуск сервера обнуляет все открытые комнаты. Обновляйте,
когда никто не играет.

## Проверка перед публикацией

В проекте есть тест, который поднимает клиент на отдельном адресе и
проходит партию целиком — ровно та схема, что получается на itch:

```
node itchtest.js
```

Запускать при работающем сервере. Он проверит, что клиент с чужого
домена умеет создавать комнату, входить по коду, начинать раунд
и получать таймер.
