# Криворучка

Пати-игра про совместное рисование, в которой управление разорвано между
игроками. Никто не может рисовать в одиночку: один тянет карандаш вправо
и вниз, другой — влево и вверх, третий решает, оставлять ли след.

Играют 2–6 человек, каждый со своего устройства. Телефон, планшет,
ноутбук — без разницы, у всех на экране и холст, и свои кнопки.
Раунд длится 60 секунд.

- **Правила и роли** — в файле [ПРАВИЛА.md](ПРАВИЛА.md).
  Его удобно скинуть игрокам перед партией.
- **Выложить игру в интернет** — в файле [ПУБЛИКАЦИЯ.md](ПУБЛИКАЦИЯ.md):
  хостинг для сервера и страница на itch.io, по шагам.
- **Устройство кода** — в файле [РАЗРАБОТКА.md](РАЗРАБОТКА.md).

---

## Что нужно

Только **Node.js** версии 18 или новее. Ни библиотек, ни базы данных,
ни регистрации.

Скачать: **nodejs.org**, кнопка с пометкой **LTS**. Ставится как обычная
программа, никаких настроек менять не нужно.

Проверить, что установился: откройте командную строку и наберите

```
node -v
```

Должен ответить номером версии.

## Запуск

1. Распакуйте папку куда угодно — например, на рабочий стол.
2. Откройте командную строку **внутри этой папки**:
   - **Windows** — зайдите в папку, щёлкните по адресной строке
     проводника (полоса вверху с путём), напечатайте поверх `cmd`
     и нажмите Enter.
   - **macOS** — правой кнопкой по папке → «Новый терминал в папке».
3. Наберите и нажмите Enter:

   ```
   node server.js
   ```

4. Окно ответит адресами:

   ```
   На этом устройстве:  http://localhost:3000/
   В своей сети Wi-Fi:  http://192.168.0.105:3000/
   ```

5. Откройте адрес в браузере, нажмите **«Создать комнату»** и отправьте
   полученную ссылку остальным.

**Окно командной строки не закрывайте.** Пока оно открыто — игра
работает. Остановить: `Ctrl+C`.

## Если кто-то не может открыть страницу

Три причины покрывают почти все случаи:

1. **Разные сети.** Все должны быть на одном Wi-Fi, и на телефонах не
   должны быть включены мобильные данные вместо него.
2. **Гостевая сеть роутера.** В этом режиме устройства намеренно не видят
   друг друга. Переключитесь на обычную сеть.
3. **Брандмауэр.** При первом запуске Windows спрашивает, разрешить ли
   Node доступ к сети — нужно ответить «Разрешить» для частных сетей.

## Комнаты

Каждая компания играет в своей комнате: свой холст, свой ведущий, своя
партия. Комнаты не пересекаются, даже если сервер один на всех.

Войти можно двумя способами: по присланной ссылке или вбив код из
четырёх букв на первом экране. Код и ссылка всегда видны в панели
«Комната», там же кнопка копирования.

Пустая комната живёт ещё двадцать минут: можно перезагрузить страницу
или на минуту потерять связь, не потеряв партию.

**Ведущий** — тот, кто зашёл первым. Он выбирает режим и состав и
начинает раунд. Если он завис или ушёл, ведение может забрать следующий
по очереди — у него появляется кнопка «Забрать ведение».

## Играть с теми, кто не рядом

Пока сервер запущен на вашем компьютере, он виден только в вашей сети.
Есть два способа открыть его наружу.

### Способ 1. Туннель — на один вечер

Быстро, без регистрации, ничего не настраивая.

1. Скачайте **cloudflared** с сайта Cloudflare. Для Windows это файл
   `cloudflared-windows-amd64.exe` — переименуйте в `cloudflared.exe`
   и положите в папку с игрой.
2. Запустите игру как обычно: `node server.js`
3. Откройте **второе** окно командной строки в той же папке и выполните:

   ```
   cloudflared tunnel --url http://localhost:3000
   ```

4. Через несколько секунд появится адрес вида
   `https://что-то-случайное.trycloudflare.com` — это публичная ссылка.
   Отправляйте её кому угодно, хоть в другой город.

Оба окна должны оставаться открытыми. При следующем запуске адрес будет
другим — для постоянной ссылки нужен второй способ.

### Способ 2. Хостинг — чтобы работало без вашего компьютера

Игра написана без зависимостей и не хранит данные на диске, поэтому её
принимает почти любой бесплатный хостинг Node: Render, Railway, Fly,
Glitch. Схема одинаковая:

1. Заведите репозиторий на GitHub и залейте туда эту папку.
2. На хостинге создайте новый Web Service из этого репозитория.
3. Команда запуска: `node server.js`. Собирать нечего — поле build
   оставьте пустым.
4. Порт хостинг задаёт сам через переменную `PORT`, сервер её уже читает.

После этого у игры будет постоянный адрес, а компьютер можно выключать.

**Что учесть на бесплатных тарифах.** Многие усыпляют сервис после
15 минут простоя — первый заход после паузы займёт около полуминуты, и
человек может решить, что ссылка не работает. Игра держит постоянное
соединение с каждым устройством (SSE), поэтому хостинг должен уметь
не рвать долгие ответы: у перечисленных выше это работает.

## На компьютере играйте с клавиатуры

Мышью две кнопки одновременно не нажать, а без этого игра не работает:
чтобы вести линию, нужно одновременно двигать карандаш и держать
«рисовать». На телефоне для этого есть два пальца, на компьютере —
клавиатура.

Буквы подписаны прямо на кнопках. Полная раскладка — в
[ПРАВИЛА.md](ПРАВИЛА.md).

За одним компьютером играет один человек: клавиши общие, а роль
у устройства одна.

## Что можно подкрутить без программирования

**Задания, время раунда, лимиты** — в начале файла `server.js`:

| Что | Переменная |
|---|---|
| Список слов | `TASKS` |
| Длительность раунда | `ROUND_S` |
| Скорость карандаша | `SPEED` |
| Насколько тормозит и разгоняет шестой игрок | `SLOW_K`, `FAST_K` |
| Сколько штампов, трясок и включений зеркала за раунд | `LIMITS` |
| Как часто прилетают помехи | `NOISE_MIN`, `NOISE_MAX` |
| Палитра | `COLORS` |
| Описания режимов | `MODES` |

После правки `server.js` перезапустите сервер: `Ctrl+C`, затем
`node server.js` снова.

**Состав ролей** — в файле `public/roles.js`, таблица `ROLESETS`: для
каждого числа игроков перечислено, кому какие кнопки достаются. Тут
достаточно обновить страницу в браузере.

## Состав папки

```
server.js            игровой сервер: комнаты, режимы, карандаш
package.json         нужен хостингу, для локального запуска не важен
build-itch.js        собирает архив для загрузки на itch.io
public/index.html    единственная страница: вход, лобби, холст, кнопки
public/roles.js      кто чем управляет при разном числе игроков
public/config.js     адрес сервера (пусто = тот же, откуда открыта страница)
tests/               самопроверки, для игры не нужны
README.md            этот файл
ПРАВИЛА.md           правила и роли — для игроков
ПУБЛИКАЦИЯ.md        как выложить игру на хостинг и itch.io
РАЗРАБОТКА.md        устройство кода — для тех, кто будет менять
```

## Самопроверки

Не нужны для игры, но полезны после любой правки кода. Запускать при
**уже работающем** сервере, из папки проекта:

```
node tests/test.js         этапы партии и все четыре режима
node tests/roomtest.js     что комнаты не мешают друг другу
node tests/mirrortest.js   зеркало и его ограничение
node tests/itchtest.js     работа клиента с отдельного домена (после сборки)
```

Четвёртый тест проверяет интерфейс целиком, открывая страницу в
эмуляторе браузера. Ему нужны две библиотеки:

```
npm install jsdom eventsource
node tests/uitest.js
```

Каждый тест печатает список проверок с пометкой `OK` или `СБОЙ`.
